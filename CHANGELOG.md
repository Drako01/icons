# Changelog

## [0.1.0] — Original Prism preview

- Four original icon systems: Prism, Daylight, Focus and High Contrast.
- 77 file types, 44 folder types, 168 extension associations, 94 named file associations and 112 folder associations.
- Native SVG icon themes with opened/closed folders, optional selection, zero runtime and no external art.
- Deterministic generator, cross-platform CI, checked VSIX, SHA-256 and documentation.

Not yet published. Manual visual/accessibility acceptance pending.
